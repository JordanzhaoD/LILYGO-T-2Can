# T-2CAN v6.0.0-beta16 发布公告 · 档杆免打扰

## 一句话

> **左手握方向，右手管速度——现在，你的换挡拨杆也能替你"轻点一下"了。**

---

## 正文（面向车主）

在方向盘后侧、右手的那个拨杆，平时你只用来上下调巡航速度。这一版，我们让它多了一个新职责：**帮你应付"请轻握方向盘"的提醒**。

以前，T-2CAN 的免打扰只有一条路——**滚轮**。它管用，但滚轮同时连着音量，清一次提醒，音量跟着动一下，有人觉得顺手，也有人觉得别扭。所以这次我们给免打扰加了**第二条路：档杆（速度拨杆）**。

### 它怎么工作

- 系统监测到"请轻握方向盘"（NAG）提醒时，自动模拟**轻轻拨一下速度拨杆**。
- 这跟你在方向盘上轻推一下拨杆、把巡航速度微调 ±1 是**同一件事**——车认为你人在、手在、注意力在，提醒自然消失。
- **全程不碰 AP 的启动/取消**。档杆的"前推取消 AP、后拨启动 AP"两个危险动作，被我们在代码层**硬锁死**，永远发不出去。

### 为什么值得你开

| | 滚轮免打扰 | 档杆免打扰（新） |
|---|---|---|
| 触发动作 | 滚轮 tick | 速度拨杆上/下拨 |
| 副作用 | 音量 ±1 | 设定速度 ±1 |
| 是否碰 AP | 否 | 否（FWD/RWD 硬禁止） |

两条路你可以**只开一条，也可以都开**——它们互不干扰，多一层兜底。

### 怎么用

1. 进 Web 面板 → **FSD 防护**页。
2. 找到「**Legacy 档杆免打扰**」开关（就在「Legacy 左滚轮免打扰」上面一行）。
3. 打开它。跑 AP 时，手离开方向盘触发提醒，看它替你拨一下、提醒消失。

> 开关默认关闭。编码已在实车（sess_137）逐帧验证过；「AP 激活状态下清除提醒」的端到端闭环，建议你上车先跑一圈确认，稳了再长开。

## 版本信息

- **版本号**：`6.0.0-beta16`
- **发布日期**：2026-11-16
- **适用硬件**：LILYGO T-2CAN（ESP32-S3 16MB）
- **更新内容**：
  - 新增「Legacy 档杆免打扰」——平行于滚轮免打扰的第二条 NAG 清除路径
  - 档杆编码层硬禁止 FWD/RWD（取消/启动 AP），结构上不碰 AP 状态
  - 修复非 P4 环境编译问题（`g_alertWatchEnabled` 条件保护）

## 技术备注（面向开发者/社群）

- **帧**：0x045 `STW_ACTN_RQ`，`SpdCtrlLvr_Stat`（data[0] bit0-5）。
- **动作编码**：上拨 `UP_1ST`(0x50)→`UP_2ND`(0x44)，下拨 `DN_1ST`(0x60)→`DN_2ND`(0x48)；清除 NAG 认 `1ST` 瞬态。实车 sess_137 逐帧 pin。
- **安全栅栏**：与滚轮 DND 同构的状态机 + 两轴安全；`forbiddenLeverRejects` 诊断兜底。
- **测试**：档杆 DND 12/12，滚轮 DND 25/25（未破坏），抓包分析器 3/3。
