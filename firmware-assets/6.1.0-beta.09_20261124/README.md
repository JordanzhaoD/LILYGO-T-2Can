# 6.1.0-beta.09 — 右滚轮按压免打扰（沿型 + 限次配对修正）

**uiBuildId**: `6.1.0-beta.09-lilygo_t2can_dual-6f67994d80b9`

## 本版修复内容

beta.08 实车判定：右滚轮按压"频繁消除，导致系统警告升级直至禁止辅助转向"。

**根因**：beta.08 把 `hands=2`（`NOT_DETECTED`，"手未在盘上"的**持续基线态**）误当成了 NAG 提示的触发条件。hands=2 在整个 AP 激活期间持续存在（1↔2 以 9-50ms 抖动），导致引擎在整段驾驶中疯狂发按压帧（抓包 221001 里持续 96.9 秒、853 帧不间断），被车辆判定为"反复滥用侧键"而 strike-out（221005：ap 状态 6→8→9→1→14，辅助转向被禁用）。

**修复**（对齐左滚轮免打扰六周稳定的语义）：

| 维度 | beta.08（错误） | beta.09（本次） |
|---|---|---|
| 警告窗 | `[2,7]`（hands=2 触发） | **`[3,6] ∪ [9,10]`**（hands=3 视觉提示才触发） |
| 触发语义 | 电平型（持续狂发） | **沿型**（警告沿才开 episode） |
| 限次 | 无限制 | **每 episode 最多 3 次** |
| 消除 | 500ms 去抖 | **立即停**（去抖删除） |

## 田野验证清单（关键）

1. **右滚轮按压单独验证**：AP 激活、手离开方向盘直到出现**视觉提示**（hands=3 起）时，观察是否只发出 1~3 帧侧键按压、且提示被消除。
2. **确认无红轮/无警告升级**：整个过程中 `ap` 状态必须保持在 6（AP 激活）不升级，尤其不能出现 8/9/14。
3. **确认 hands=2 静默期不动作**：AP 激活但手未上盘（hands=2 基线）时，引擎应**完全不发按压帧**（这是 beta.08 崩坏的根因，本次重点验证）。
4. 若仍异常，抓包发回（重点看 0x399 的 hands 状态 + 0x045 的 b4 按压帧时序）。
