# 固件资产 6.1.0-beta.10（2026-11-25）— 右滚轮中央键点击免打扰

**uiBuildId**: `6.1.0-beta.10-lilygo_t2can_dual-47bc051b65c4`

## 本版做了什么

右滚轮按压回到**中央键**，并且改成「点击」形态：按下帧后立刻补一帧松开帧。

### 依据（beta.05–09 共 23 份实车录制）

| 按压信号 | 版本 | 警告回合 | 结果 |
|---|---|---|---|
| 中央键 0x0010 | beta.07 | 6 | 6 次全部清除，其中 2 次只发 1 帧（9–26ms） |
| 侧键 0x0020 | beta.09 | 8 | 6 次未清除（警告持续 6–15 秒）；另 2 次是警告自行消失 |
| 侧键 + hands=2 触发 | beta.08 | — | 96.9 秒连发 853 帧 → 警告升级直至禁止辅助转向 |

两个引擎的发帧骨架完全相同，只有按键位不同。beta.08 把按压位从中央改到侧键，是 beta.09 无效的原因。

### 为什么要补松开帧

按中央键会弹出车机菜单（如「手机未连接」），而且每次按压都弹。原来的引擎发完按压帧后，要等车辆自己的下一个原生帧（约 100ms）才等于「松开」——车机看到的是一个按住不放的按键。真实按键在总线上是「按下帧 + 紧跟的松开帧」。本版照此发出尽可能短的点击。

**这是否短到让车机不弹菜单，需要实车验证——本版就是为回答这个问题而出的。**

### 改动清单

- 按压位改回中央键（`data[4] 0x10`）
- 每次点击 = 按下帧 + 立即的松开帧；发送失败的按下帧不再补松开帧
- 每轮警告最多 **2 次点击**（原 3 次）；第二次点击需要：松开帧已发、之后来了新的原生空闲帧、且距松开帧 ≥150ms
- 左滚轮免打扰的让路延长到松开帧之后
- 触发条件不变：只在提醒阶梯 hands 3–6 / 9–10 出现时触发；hands=2 是「手未上盘」的常态，不触发
- **界面**：右滚轮开关下方新增状态数据表（与左滚轮免打扰同构）——告警状态 / 原生 0x045 / 状态·本轮点击·上限 / 按下·松开·发送失败 / 回声·动作帧 / 提醒轮次·自愈 / 阻断原因
- 开关徽标改回「实验」

## 田野验证（关键）

1. **警告是否清除**：出现提醒后，状态表「按下/松开」应变成 `1 / 1`（或 `2 / 2`），提醒随之消失。
2. **菜单是否还弹**：这是本版的核心问题。请记录每次按压是否弹出菜单。
3. **hands=2 期间不动作**：AP 激活、手未上盘但还没出提醒时，「按下」计数应不增长。
4. **无红方向盘、无警告升级**：全程不应出现红轮。
5. 跑完抓 `/status` 与抓包回传。

## 读状态表

| 现象 | 含义 |
|---|---|
| 按下 = 松开 | 点击完整发出 |
| 按下 > 松开 | 有按下帧发送失败（看「发送失败」） |
| 阻断原因 = `release_pending` / `spacing` | 节奏保护在起作用，正常 |
| 阻断原因 = `episode_limit` | 本轮 2 次已用完，提醒仍未清除 |
| 阻断原因 = `idle` | 没有提醒，引擎待命 |
