手机端重新定义为“现场遥控器”

当前移动端是桌面页面的压缩：卡片多、信息密度高、操作按钮分散。新方案把手机首页变成一个原生 App 风格的远程控制卡片，只承载现场最常用动作。

危险操作交互规则

  • FSD 注入启用使用 Hold-to-enable，不使用普通 toggle。
  • 重启、爆闪、Service Mode 放入二级页并二次确认。
  • 底部 Tab 保留 5 个入口：Home / Drive / Speed / Network / More。

适合热点现场使用

大按钮、浅色手机主题、单手 thumb zone、清晰连接状态，比现在的深色小卡片更适合户外和车内临时操作。

Why this page is dense
