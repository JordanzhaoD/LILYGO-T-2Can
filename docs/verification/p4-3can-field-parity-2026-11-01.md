# Atlas-P4-3CAN 实车 Parity 清单（2026-11-01）

> T2CAN → P4-3CAN 原封移植的实车验收。基线：车上 T2CAN 板实跑的
> 6.0.0-beta07。逐项对齐 = 移植收口；异常记拒因码/现象回填。

## 🚫 红线（置顶，跳过即事故风险）

1. **上车前物理拔掉 T2CAN 板。** 两个可 TX 设备同总线 = 事故。
   P4 板接 X179 前，先确认 T2CAN 板已从车上移除。
2. P4 接线：CanA → X179 13/14（DAS 主线），CanB → X179 9/10（滚轮/
   拨杆总线）。CanC 不接。
3. 车内升级只用 WebUI OTA（或 esptool 单写 app@0x20000）——首烧四段链
   之后永不再动 bootloader/分区表。

## 前置确认（台架 Task 4 已过的项，上车前 30 秒复核）

- [ ] 上电 boot 横幅正常（无 boot loop、无 SPIRAM 报错）
- [ ] 串口日志见 `CAN B (TWAI1) ready @ 500k`

- [ ] 板名/module 字段 = Atlas-P4-3CAN，界面与 T2CAN 一致

## 回填区

**2026-11-01 试驾回填（Jordan 报告 + IMG_4626）**：

- ✅ **三路 CAN 全部接通**（本清单模板写于 CanC 接线前，实际已接
  CanC → X179 18/19）：三总线通讯正常，车机 UI 三路计数全活
  （IMG_4626 为证）。三总线实车同跑 = 移植首验。
- ✅ 大部分 parity 项与 T2CAN 行为一致（未逐项打勾，Jordan 口头
  确认「大部分功能都正常」）。
- ❌ **问题 1（P0，阻断录制链）**：AP-STA 共存不稳。设置上游 STA 后，
  车机/手机连 AP「连接上一会儿被判定为没有互联网连接，断掉」；
  点开录制即断连 → **本次实车数据帧零录制**。T2CAN 同场景稳定。
- ⚠️ **问题 2（待录制后分析）**：DND（滚轮免打扰）偶发失效，疑与
  3CAN 总线选择有关；因问题 1 无法录制，暂只有现象描述。
