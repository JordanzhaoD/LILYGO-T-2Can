## 0. 一句话总结

本车换挡**执行通路首次实锤**：拨杆下压 = CanC 0x228 上的**两相瞬态脉冲**
（C4×5帧→C8×18帧→回 C0），领先挡位翻转 ~60ms，CRC 全通过；请求/反馈镜像在
CanC 0x116（PT 副本）与 CanA 0x118 双路可见。v1 的注入假设从"Albert 移植推测"
升级为"本车原生观测"——但只覆盖 **D 方向**；R 方向位、P 钮载体、速度场、障碍物位
本轮数据不可判，留在哨兵。

**新增冻结（结构层，非 kAsProfile 项）**：
- 0x116（CanC）= 0x118 的 PT 侧镜像：FF,请求b1,244,挡b3,counter,crc —— 请求码
  P=0x9x / N=0xBx / D=0xCx（b1 高半字节；bit4=1Hz 活位翻转；idle=0x1x）。
  R=0xAx 推断（9,B,C 已证，10 补位），**未观测**。
- 请求/挡位时序：0x228 脉冲(-61ms) → 0x116 挡位翻转(+1ms) → 0x116 请求码回填(+19ms)
  → 0x228 回 idle(+169ms)。注入因果链完整。

  内齐发）但 0x228 全程 idle → **P 钮不走 0x228**，输入载体未定。

## 2. 对 v1 引擎的裁定（进台账）

1. **Composer 语义 = 瞬态脉冲而非持续状态**：本车原生命令是 C4(50ms)→C8(180ms)→回
   idle 的脉冲；Albert 的"持续写对"模型不适用。近似案：仅 C8×~20 帧（C4 是机械过渡，
   监听方大概率只锁存 C8 沿）——Stage B 先试 C8-only，失败再上两相。
2. **Stage B 可试面收窄为 D 方向单命令**（C8 脉冲，自 P 或 N 入 D 假设同码）。
   R/P/N 命令缺数据，不入 Stage B。
3. **0x116 可作第二确认源**（PT 侧镜像与 0x118 同码同拍），v1 confirm 逻辑可加冗余但
   非必需。
4. 速度/障碍物哨兵 → 门链保持 fail-closed，v1 即便常量落地也**不会**发射，直到
   补充侦查关闭哨兵或 Jordan 明示门政策变更（不建议）。
